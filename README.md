## 📁 Struktur Repositori
* `index.html` - Halaman web utama yang memuat kerangka UI untuk seluruh latihan, mini project, dan eksperimen mandiri.
* `script.js` - Logika JavaScript untuk interaktivitas, kalkulasi, validasi input, dan manipulasi DOM.
* `README.md` - Dokumentasi dan penjelasan repositori.

## ✨ Fitur & Isi Praktikum

1. **Dasar JavaScript & Output**: Output pesan `Hello World` dan dialog interaktif menggunakan `prompt` & `alert`.
2. **Operasi Aritmetika**: Implementasi fungsi perhitungan matematika dasar pada *console*.
3. **Seleksi Kondisi**: Penggunaan struktur percabangan `if-else` dan `switch-case`.
4. **Cek Bilangan Genap/Ganjil**: Memeriksa jenis bilangan bulat secara langsung dari input HTML.
5. **Ubah Warna Latar Halaman**: Mengubah warna *background* halaman web secara dinamis melalui tombol.
6. **Kalkulasi Total Menu Makanan**: Menghitung otomatis total harga makanan berdasarkan pilihan *checkbox*.
7. **Mini Project (Kalkulator Nilai Mahasiswa)**:
   - Perhitungan Nilai Akhir berbasis bobot: **Tugas (30%)**, **UTS (30%)**, dan **UAS (40%)**.
   - Validasi input (rentang 0–100 dan wajib diisi).
   - Penentuan Predikat (A, B, C, D, E) serta Status Kelulusan.
8. **Eksperimen Mandiri**: Menampilkan **Tabel Perkalian Angka 7** (1–10) secara otomatis menggunakan *looping* `for` dan manipulasi DOM.
